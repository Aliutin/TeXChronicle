# TeXChronicle provenance notice

TeXChronicle began as a fork of
[MagicTeX MCP](https://github.com/ZoeLinUTS/MagicTeX-mcp), created by Zoe Lin and
its contributors. The source has since been substantially modified and expanded,
including human-facing launchers, editable Live view, section-aware history,
render-linked checkpoints, project-local comments, broader project/file preview,
and a self-contained Windows distribution.

This modified project is independently named and maintained as TeXChronicle. It
is distributed under the GNU Affero General Public License, version 3 or later;
see [LICENSE](LICENSE). Git history preserves the detailed authorship of the
upstream work and later modifications.
